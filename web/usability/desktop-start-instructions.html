Desktop empty-canvas Instructions lead with how to start

Before this fix, the desktop empty canvas showed playback keyboard shortcuts (Step / Segment / Candidate) before any trajectory was loaded. Novices who skipped the tour saw expert replay keys instead of the start path. Mobile already listed start steps; desktop now matches, and the picker / status copy says trajectory instead of bare “trace”.

Before
Select trace…

Instructions

  • ← / →: Previous / next step
  • Shift + ← / →: Previous / next segment
  • Space: Play / pause
  • C / X: Next / previous candidate
  • Drag: Pan
  • Scroll: Zoom
After
Select trajectory…

Instructions

  • Select a preloaded trajectory or click Upload trajectory.
  • Optionally adjust ε match (accuracy) and δ grid (search spacing), then press Load.
  • After load, open Results for scores. With a preloaded trajectory you can pick optional Compare algorithms and press Run.
  • Drag to pan and scroll to zoom. Keyboard shortcuts live in the right-side Instructions after load.

Empty-canvas Instructions teach the start path. Picker placeholder says Select trajectory… (scrollWidth check runs in the screenshot harness).
